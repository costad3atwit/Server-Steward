# Example: notes about a stack

Write one file per stack or task. The admin agent retrieves these when you ask it questions
in Discord. It never treats them as instructions, only as information.

## What it is
Describe what the stack does and which containers belong to it.

## What restarting it affects
For example: "Restarting interrupts anyone currently streaming."

## Known issues
Anything you've had to fix before, and what fixed it.
