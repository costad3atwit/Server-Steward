# Getting started

## How do I get access?
Ask the server admin for an invite. You'll get a message with a link to join and the accounts you've been given.

## Which address do I use for each service?
Replace this with a list of your services and their addresses, for example:

- Movies and shows: `https://media.example.com`
- Photos: `https://photos.example.com`

## Who do I contact if something isn't working?
Use the question box on this page. If the answer isn't in these help pages, your question is passed on to the admin.
